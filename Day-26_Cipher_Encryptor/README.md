# 🔐 Day 26: Classical Cipher Encryption & Decryption

A fundamental cryptography suite featuring Caesar Substitution Cipher (with encryption, decryption, and exhaustive 25-key brute-force cracking) alongside the polyalphabetic Vigenère Cipher.

---

## 📌 Concepts Covered
- Character code arithmetic using `ord()` and `chr()`.
- Modular arithmetic (`% 26`) for circular alphabet wrapping.
- Preservation of letter capitalization and special symbols.
- Cryptanalysis via brute-force permutation search.

---

## 🚀 How to Run

```bash
python 26_Cipher_Encryptor.py
```
