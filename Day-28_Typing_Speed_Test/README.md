# ⌨️ Day 28: Typing Speed & Accuracy Tester

A CLI typing benchmark test that calculates Words Per Minute (WPM), elapsed typing time in seconds, and character-level accuracy percentages with rank evaluations.

---

## 📌 Concepts Covered
- High-precision timestamp delta measurements with `time.time()`.
- Standard Words-Per-Minute (WPM) formulation: $\text{WPM} = \frac{\text{Words}}{\text{Elapsed Minutes}}$.
- `zip()` pairwise iterator comparison for accuracy scoring.
- Rank classifications and feedback strings.

---

## 🚀 How to Run

```bash
python 28_Typing_Speed_Test.py
```
