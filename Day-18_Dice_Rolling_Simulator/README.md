# 🎲 Day 18: Dice Rolling Simulator & Statistical Analyzer

A visual 6-sided dice rolling simulator supporting simultaneous multiple dice rendering using multi-line ASCII graphics, alongside a Monte Carlo statistical simulation engine with terminal bar charts.

---

## 📌 Concepts Covered
- Multi-line ASCII block rendering combining side-by-side strings.
- Pseudo-random number generation (`random.randint`).
- Frequency analysis using `collections.Counter`.
- Terminal visualization with ASCII bar charts (`█`).

---

## 🚀 How to Run

```bash
python 18_Dice_Rolling_Simulator.py
```
