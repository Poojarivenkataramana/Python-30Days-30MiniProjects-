# 🪢 Day 17: Hangman Word Game

A console implementation of the traditional Hangman word-guessing game featuring multi-stage ASCII graphics, categorized word lists (Tech, Animals, Geography), guess validation, and remaining life counters.

---

## 📌 Concepts Covered
- Python `set` collection for $O(1)$ lookup of previously guessed letters.
- Multi-line ASCII art lists mapped to game error states.
- List comprehension for rendering dynamic masked string states (`_ _ A _ _`).
- Replay and game loops.

---

## 🚀 How to Run

```bash
python 17_Hangman_Game.py
```
