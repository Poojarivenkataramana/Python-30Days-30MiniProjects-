# 🌤️ Day 29: Weather Forecast Formatter & CLI Viewer

A weather lookup and report formatting terminal application using Python standard library `urllib.request` for live online weather metrics (no API key required) with an integrated offline cache for offline environments.

---

## 📌 Concepts Covered
- Standard library networking with `urllib.request` and HTTP headers.
- Safe JSON API parsing with `json.loads()`.
- Resilient offline fallback database architecture.
- Celsius to Fahrenheit temperature conversion formulas.

---

## 🚀 How to Run

```bash
python 29_Weather_App.py
```
