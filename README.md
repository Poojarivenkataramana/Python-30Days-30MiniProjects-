## 🛠️ Skills & Concepts Mastered

- **Core Python**: Variables, Data Types, Type Casting, String Methods & Slicing (`[::-1]`).
- **Control Flow**: Conditional Logic (`if-elif-else`), Loops (`while`, `for`, `enumerate`, `zip`).
- **Data Structures**: Lists, Tuples, Sets, Dictionaries, Nested Structures, List Comprehensions.
- **Functions & Modularity**: Default arguments, return values, helper utilities, lambda expressions.
- **Standard Library Modules**: `random`, `math`, `time`, `datetime`, `json`, `os`, `shutil`, `re`, `hashlib`, `string`, `urllib.request`.
- **File I/O & Persistence**: Reading/Writing JSON documents, path operations, safe directory creation.
- **Terminal UI/UX**: ASCII Art banners, live carriage-return counters (`\r`), input validation and formatted tabular report cards.

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Poojarivenkataramana/Python-30Days-30MiniProjects-.git
cd Python-30Days-30MiniProjects-
```

### 2. Run any project
Navigate to any day's directory or execute directly:
```bash
# Example: Run Day 04 Number Guessing Game
python Day-04_Number_Guessing_Game/04_Number_Guessing_Game.py

# Example: Run Day 20 Tic-Tac-Toe
python Day-20_Tic_Tac_Toe/20_Tic_Tac_Toe.py
```
