# 💰 Day 15: Daily Expense Tracker

A command-line personal finance tracker that logs expenditures with dates, categorization tags, automated percentage distribution summaries, and persistent JSON storage.

---

## 📌 Concepts Covered
- Python `datetime` formatting (`strftime("%Y-%m-%d %H:%M")`).
- JSON document persistence (`expenses.json`).
- Categorical aggregation and sorting with `lambda` expressions.
- Percentage allocation metrics.

---

## 🚀 How to Run

```bash
python 15_Expense_Tracker.py
```
