# ⏰ Day 21: CLI Alarm Clock

A command-line alarm system that monitors system time against targeted schedules, computes remaining duration with live console ticks, triggers terminal alert audio cues (`\a`), and provides interactive Snooze/Dismiss actions.

---

## 📌 Concepts Covered
- Python `datetime` and `timedelta` time arithmetic.
- Dynamic time comparison and automatic next-day rollover logic.
- Real-time formatted console status ticker using `\r`.
- Interrupt handling and snooze loops.

---

## 🚀 How to Run

```bash
python 21_Alarm_Clock.py
```
