# 📝 Day 08: Word & Character Text Analyzer

A text analysis utility that inspects paragraphs of text to calculate comprehensive statistics including word count, character count (with/without whitespace), average word length, sentence count, vowel/consonant frequencies, and top common words.

---

## 📌 Concepts Covered
- String operations (`splitlines()`, `replace()`, `strip()`).
- Regular expressions (`re.findall()`, `re.split()`) for tokenization.
- `collections.Counter` for frequency distribution.
- Interactive multi-line console input handling.

---

## 🚀 How to Run

```bash
python 08_Word_Counter.py
```
