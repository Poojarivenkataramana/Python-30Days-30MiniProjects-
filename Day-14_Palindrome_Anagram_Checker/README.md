# 🔤 Day 14: Palindrome & Anagram Checker

A string analysis utility that checks whether words or full sentences read identically forwards and backwards (Palindromes) and whether two phrases contain exact permutations of each other (Anagrams).

---

## 📌 Concepts Covered
- Python string slicing step syntax `[::-1]` for fast reversal.
- `sorted()` on strings for comparing character frequency profiles.
- Regular expressions `re.sub()` for removing whitespace, capitalization, and punctuation.

---

## 🚀 How to Run

```bash
python 14_Palindrome_Anagram_Checker.py
```
