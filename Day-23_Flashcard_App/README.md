# 🗂️ Day 23: Flashcard Study Quizzer

An active recall study companion designed for flashcard memorization, deck creation, interactive card flipping, and retention rate scoring with JSON persistence.

---

## 📌 Concepts Covered
- Nested dictionary and list state representations.
- Interactive prompt-driven active recall workflow.
- In-place card shuffling using `random.shuffle()`.
- Dynamic deck creation and file serialization.

---

## 🚀 How to Run

```bash
python 23_Flashcard_App.py
```
