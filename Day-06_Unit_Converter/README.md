# 🔄 Day 06: Universal Unit Converter

A modular Python command-line utility for converting values across various unit systems including Temperature (Celsius, Fahrenheit, Kelvin), Length (Meters, Kilometers, Miles, Feet, etc.), and Weight (Kilograms, Grams, Pounds, Ounces).

---

## 📌 Concepts Covered
- Python functions with argument passing and return values.
- Dictionary-based conversion factor tables.
- Two-step normalized conversions (e.g. converting to a base SI unit then to the target unit).
- User input handling and loop menus.

---

## 🚀 How to Run

```bash
python 06_Unit_Converter.py
```
