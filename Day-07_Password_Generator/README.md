# 🔐 Day 07: Secure Password Generator & Strength Checker

A versatile Python tool to generate strong, randomized passwords based on user preferences and evaluate password strength using security scoring heuristics.

---

## 📌 Concepts Covered
- `string` module constants (`ascii_uppercase`, `ascii_lowercase`, `digits`, `punctuation`).
- `random.choice()` and `random.shuffle()` for cryptographic randomness.
- Password entropy & strength scoring heuristics.
- Flexible user configuration with default fallbacks.

---

## 🚀 How to Run

```bash
python 07_Password_Generator.py
```
