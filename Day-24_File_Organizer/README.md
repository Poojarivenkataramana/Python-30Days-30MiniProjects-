# 📁 Day 24: Automatic File Organizer & Desktop Cleaner

An automated operating system maintenance utility that scans directories, sorts files by format into organized folders (`Images`, `Documents`, `Audio`, `Videos`, `Archives`, `Code`), and supports safe dry-run preview modes.

---

## 📌 Concepts Covered
- File system manipulation using `os` and `shutil` (`os.listdir`, `os.path.splitext`, `os.makedirs`, `shutil.move`).
- Extension mapping with nested collections.
- Safe Dry-Run preview execution patterns.
- Collision avoidance for duplicate filenames.

---

## 🚀 How to Run

```bash
python 24_File_Organizer.py
```
