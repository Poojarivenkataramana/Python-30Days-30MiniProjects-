# 📡 Day 13: Morse Code Translator

A bidirectional encoder and decoder that translates plain English text into Morse code and converts Morse code signals back into readable English text.

---

## 📌 Concepts Covered
- Dictionary key-value lookups and reverse dictionary comprehension (`{v: k for k, v in d.items()}`).
- Tokenization with `.split()` and formatting with `.join()`.
- Error handling for unsupported punctuation characters.

---

## 🚀 How to Run

```bash
python 13_Morse_Code_Translator.py
```
