# 📖 Day 30: Secure Personal Diary & Journal

A password-protected personal journal CLI application that uses SHA-256 cryptographic password hashing, timestamped reflections, mood tags, search filters, and persistent storage in `diary.json`.

---

## 📌 Concepts Covered
- Password security and hashing using `hashlib.sha256()`.
- Multi-line console input loops.
- Reverse chronological sorting and filtering.
- JSON structure serialization and access control state machines.

---

## 🚀 How to Run

```bash
python 30_Personal_Diary.py
```
