# ⏱️ Day 12: Countdown Timer & Stopwatch

A dual-purpose time tracking CLI utility featuring an in-place updating countdown timer with audio chime and a precision stopwatch supporting live lap splits.

---

## 📌 Concepts Covered
- Python `time` module (`time.sleep()`, `time.time()`).
- In-place terminal rendering with carriage return `\r` and `flush=True`.
- `divmod()` arithmetic for calculating hours, minutes, and seconds.
- Handling `KeyboardInterrupt` (Ctrl+C) gracefully.

---

## 🚀 How to Run

```bash
python 12_Countdown_Timer.py
```
