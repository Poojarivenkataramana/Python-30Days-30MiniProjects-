# ✊ Day 05: Rock, Paper, Scissors Game

A classic Rock, Paper, Scissors game played against the computer with ASCII art animations, continuous score tracking, and an overall final match summary.

---

## 📌 Concepts Covered
- `random.choice()` for randomized computer moves.
- Dictionary mappings for abbreviations (`r` -> `rock`, etc.).
- Multi-condition evaluation logic.
- Dynamic scoreboard and ASCII art display.

---

## 🎮 Game Rules
- ✊ **Rock** beats ✌️ **Scissors**
- ✌️ **Scissors** beats ✋ **Paper**
- ✋ **Paper** beats ✊ **Rock**

---

## 🚀 How to Run

```bash
python 05_Rock_Paper_Scissors.py
```
