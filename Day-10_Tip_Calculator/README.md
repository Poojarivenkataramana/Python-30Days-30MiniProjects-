# 💵 Day 10: Tip & Split Bill Calculator

A practical financial calculator designed to compute gratuity / tip amounts, total bill including tips, and the exact per-person share when splitting expenses with friends.

---

## 📌 Concepts Covered
- Formatted floating-point precision (`:.2f`, string alignment `:<`, `:>`).
- Gratuity rate formulas and split division.
- Input bounds validation and error recovery.

---

## 🚀 How to Run

```bash
python 10_Tip_Calculator.py
```
