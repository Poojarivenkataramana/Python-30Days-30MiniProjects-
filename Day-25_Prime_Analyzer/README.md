# 🔢 Day 25: Prime Number & Factorization Analyzer

A mathematical analysis tool designed to test primality in $O(\sqrt{N})$ time, enumerate all divisors, extract prime numbers within an arbitrary interval $[A, B]$, and generate canonical prime power factorizations ($N = p_1^{e_1} \times p_2^{e_2} \dots$).

---

## 📌 Concepts Covered
- Efficient $O(\sqrt{N})$ factor extraction using `math.isqrt()`.
- Prime factorization decomposition using division algorithms.
- List sorting and formula string formatting.

---

## 🚀 How to Run

```bash
python 25_Prime_Analyzer.py
```
