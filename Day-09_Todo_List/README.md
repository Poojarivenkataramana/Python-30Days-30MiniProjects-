# 📝 Day 09: CLI To-Do List Application

A persistent task management tool designed for the command line with task creation, priority tags (Low/Medium/High), completion toggles, deletion, and automatic JSON file persistence (`tasks.json`).

---

## 📌 Concepts Covered
- CRUD (Create, Read, Update, Delete) data operations.
- Python `json` library (`json.load()`, `json.dump()`).
- File persistence and `os.path.exists()` checks.
- List indexing and bounds error prevention.

---

## 🚀 How to Run

```bash
python 09_Todo_List.py
```
