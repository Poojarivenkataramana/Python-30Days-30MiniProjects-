# 🔥 Day 27: Habit Tracker & Streak Counter

A daily self-improvement and accountability tracker that monitors habits, logs calendar completions, maintains consecutive daily streak metrics, and persists data across sessions in `habits.json`.

---

## 📌 Concepts Covered
- Calendar date handling and difference comparisons with `datetime.date` and `timedelta`.
- Consecutive streak calculation algorithms.
- Data persistence with JSON serialization.
- Dashboard formatting and status indicators.

---

## 🚀 How to Run

```bash
python 27_Habit_Tracker.py
```
