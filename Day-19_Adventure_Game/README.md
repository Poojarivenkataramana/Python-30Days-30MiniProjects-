# 🗡️ Day 19: Text-Based RPG Adventure Game

An interactive fantasy narrative adventure featuring animated typewriter text, dynamic player inventory management, health mechanics, branching decision nodes, combat encounters, and multiple game endings.

---

## 📌 Concepts Covered
- Managing mutable game state using Python dictionaries.
- Function chaining to construct decision-tree narrative paths.
- Typewriter-style animated text output using `time.sleep()` and `flush=True`.
- Conditional branch logic and inventory requirements.

---

## 🚀 How to Run

```bash
python 19_Adventure_Game.py
```
