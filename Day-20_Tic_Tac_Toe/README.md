# ⭕ ❌ Day 20: Tic-Tac-Toe Game (2-Player & AI)

A 3x3 grid console Tic-Tac-Toe game supporting both 2-Player local pass-and-play and Single Player mode against a smart rule-based AI that predicts wins, blocks opponent threats, and seizes optimal board control.

---

## 📌 Concepts Covered
- 1D/2D grid representation and slicing.
- Win condition validation matrices (rows, columns, diagonals).
- AI decision trees (Win check -> Block check -> Center -> Corners).
- State alternation between turns.

---

## 🚀 How to Run

```bash
python 20_Tic_Tac_Toe.py
```
