# 📒 Day 16: Contact Book Management System

A contact directory utility that allows users to create, search, list, and delete personal contacts (name, phone, email, address) with search filters and JSON persistence.

---

## 📌 Concepts Covered
- In-memory querying and case-insensitive search matching.
- Sorting lists of dictionaries with key functions.
- JSON database storage (`contacts.json`).
- Input format validation.

---

## 🚀 How to Run

```bash
python 16_Contact_Book.py
```
